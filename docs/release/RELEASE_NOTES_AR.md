# ملاحظات الإصدار — العربية

## 1.0.0 (رقم البناء 1)

نص «ما الجديد» للمتجر (≤ 500 حرف):

```
الإصدار الأول من حصن المسلم:
• أذكار الصباح والمساء والنوم والصلاة والسفر وغيرها في 13 قسمًا
• أدعية من القرآن الكريم والأدعية النبوية
• عدّاد للتكرار وتقدّم يومي محفوظ
• مسبحة إلكترونية بأهداف وإحصائيات
• بحث فوري ومفضلة وتذكيرات اختيارية
• وضع داكن وواجهة عربية وإنجليزية
• يعمل دون إنترنت، بلا إعلانات ولا تتبّع
```
